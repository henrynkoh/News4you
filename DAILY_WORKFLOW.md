# News4you Daily Workflow

## Schedule

Run at 00:00, 06:00, 12:00, and 18:00 America/Los_Angeles.

## Define

The unit is one original public YouTube Short on @News4youa. The source topic is selected through the documented Social Blade ranking proxy. The source video is evidence and a topic lead, never a media asset library.

## Measure and select

1. Verify Social Blade filters: YouTube, Global, All categories, Top, ordered by Views.
2. Capture the visible #1 creator, total views shown, source URL, and Pacific observation time.
3. Open the creator's official YouTube channel and Videos > Latest.
4. Select the newest public upload whose video ID is not in state.completed.
5. Record source video ID, title, URL, publication date, visible age/view count if available, and the exact facts used.
6. If the ranking, channel identity, latest order, or source ownership is unclear, stop.

## Analyze and write

Create a factual 20-45 second news brief that answers: what was released, who released it, when it appeared, and why it was selected. Use independent wording. Do not repeat lyrics, reproduce plot/creative expression, or imply endorsement.

## Produce

- Original vector, diagram, typography, or documented licensed stock visuals.
- Authorized narration and original burned captions.
- No source footage, audio, music, thumbnail, channel art, lyrics, or description copying.
- Source attribution and independent-news notice in the description.
- 1080x1920 H.264/AAC, 20-45 seconds.

## Control and publish

1. Run all gates in QUALITY_GATES.md.
2. Verify the active channel is News4you (@News4youa).
3. Set AI use truthfully, paid promotion truthfully, and audience truthfully.
4. Wait for YouTube checks. Do not publish if a blocking copyright result appears.
5. Publish Public, open the public page, and verify title, description, attribution, settings, playback, and source link.
6. Update state atomically only after successful verification.

## Report

Report the ranking evidence, source creator/video, transformation summary, media-rights coverage, defects/rework, public URL, and next run time.
