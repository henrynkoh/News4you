# Copyright and Transformation Policy

News4you may report the same public topic, names, release title, date, and other facts. Facts and short source-identifying quotations are used only as needed for attribution.

News4you must not:

- download, screen-record, crop, recolor, mirror, animate, or lightly edit the source video;
- reuse source music, audio, lyrics, thumbnail, still frames, channel art, or description copy;
- imitate the original scene sequence, narration, or distinctive creative treatment;
- suggest sponsorship, authorization, or affiliation that does not exist.

Every video must use a new script and original composition. Source links belong in the description. When a topic cannot be covered meaningfully without copying protected expression, skip it.
