# News4you

News4you is a four-times-daily YouTube Shorts news workflow for [@News4youa](https://www.youtube.com/@News4youa).

## Schedule

Runs every day at **12:00 AM, 6:00 AM, 12:00 PM, and 6:00 PM America/Los_Angeles**.

## Selection rule

1. Open Social Blade's **Top 100 YouTube Creators by Views**, with Global / All / Top / Views selected.
2. Record the visible #1 creator, ranking value, source URL, and observation time.
3. Open that creator's YouTube **Videos > Latest** list.
4. Select the newest public upload not already recorded in `NEWS4YOU_STATE.json`.
5. If there is no unprocessed upload, stop rather than manufacture a duplicate.

Social Blade ranks channels, not individual videos. News4you therefore discloses this two-step proxy: **#1 channel by total views, then newest unprocessed public upload from that channel**.

## Creative rule

News4you covers the same public topic as a short, independent news brief. It does **not** copy or lightly edit the source video's footage, audio, music, lyrics, thumbnail, script, title, or description. Every published Short uses original wording, original or documented licensed graphics, original captions, and authorized narration.

## Quality policy

- 20-45 seconds, 1080x1920, H.264/AAC.
- Exact source attribution and observation time.
- No false affiliation, ranking, view-count, or breaking-news claim.
- No third-party music, footage, thumbnails, screenshots, or lyrics unless separately licensed and logged.
- AI disclosure set truthfully; not made for kids unless the content genuinely is.
- Publish only after copyright checks show no blocking issue and Studio verification passes.
